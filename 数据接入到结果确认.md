## 条件配置

展示口径和入库口径分开。不命中展示规则的单仍在库里，只是页面上不计入。名单或规则命中任一个就不展示。

`backend/src/view_filter.rs`

```rust
pub fn verdict(
    filter: Option<&RuleNode>,
    lists: &[ListRule],
    sets: &ListSets,
    schema: &RecordSchema,
    record: &dyn RecordValues,
) -> Verdict {
    let out_lists = sets.matched_list_settings(lists, record);
    if !out_lists.is_empty() {
        return Verdict { passed: false, out_lists };
    }
    Verdict {
        passed: filter.is_none_or(|rule| crate::rule_tree::eval(Some(rule), schema, record)),
        out_lists,
    }
}
```

规则本身是条件树。节点可以是条件、并且、或者、非。

`backend/src/rule_tree.rs`

```rust
pub fn eval(tree: Option<&RuleNode>, schema: &RecordSchema, record: &dyn RecordValues) -> bool {
    let Some(node) = tree else {
        return false;
    };
    let base = match node.kind.as_str() {
        "condition" => node
            .condition
            .as_ref()
            .map(|c| field_matches(schema, record, &c.field, &c.op, &c.value, &c.value2) ^ c.negate)
            .unwrap_or(false),
        "and" => node.children.iter().all(|child| eval(Some(child), schema, record)),
        "or" => node.children.iter().any(|child| eval(Some(child), schema, record)),
```

Issue 默认展示口径是「状态不是 closed，也不是 close」。

## 进展跟踪

当天的进展按单、按日期写入。同一天再改是覆盖。清空则删掉这一天。

`backend/src/db/attack.rs`

```rust
pub async fn set_issue_progress(
    pool: &SqlitePool,
    url: &str,
    progress: Option<&str>,
    updated_by: &str,
) -> anyhow::Result<()> {
    if let Some(progress) = progress {
        sqlx::query(
            r#"INSERT INTO issue_progress_history (issue_url, progress_day, body, updated_by, updated_at)
               VALUES (?, ?, ?, ?, ?)
               ON CONFLICT(issue_url, progress_day) DO UPDATE SET
                 body=excluded.body, updated_by=excluded.updated_by, updated_at=excluded.updated_at"#,
        )
        .bind(url)
        .bind(crate::timeutil::today_shanghai().to_string())
        .bind(progress)
        .bind(updated_by)
        .bind(now_rfc3339())
        .execute(pool)
        .await?;
    } else {
        sqlx::query("DELETE FROM issue_progress_history WHERE issue_url = ? AND progress_day = ?")
            .bind(url)
            .bind(crate::timeutil::today_shanghai().to_string())
            .execute(pool)
            .await?;
    }
    Ok(())
}
```

## 结果确认

关闭才算出结果。`resolved` 只表示待测试，单仍然开着，还要继续满足闭环期限。`pending` 和 `stale` 退出闭环窗口。

`backend/src/ecosystem.rs`

```rust

```

bug 的闭环窗口是创建日起 7 个工作日，feature 是 30 个工作日。

```rust
pub const BUG_WORKDAYS: i64 = 7;
pub const FEATURE_WORKDAYS: i64 = 30;
```

攻关当天的实绩把 resolved 从「待开发」里拿开，但没有把它当成已关闭。
